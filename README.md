## Featured Projects

These projects are publicly available on my GitHub.

### [ABHL — Integrated Dam Management & Data Platform](https://github.com/ranya20/abhl-barrages-platform-demo)

Integrated **Data & AI platform developed during my engineering internship at the Loukkos Hydraulic Basin Agency (ABHL)** for the management, monitoring, and analysis of dam-related hydraulic data.

Built with **FastAPI, React, PostgreSQL, and Python**, the platform centralizes hydraulic data and business rules within a modular information system.

It combines:

- hydraulic monitoring and calculations;
- interactive dashboards and historical analysis;
- daily and monthly operational workflows;
- versioned rating curves;
- dam and user administration;
- role-based access control and audit mechanisms;
- Excel/PDF reporting workflows;
- a secured **Natural Language-to-SQL data assistant** for querying hydraulic information.

The public repository contains a sanitized version of the project without internal agency data, credentials, database backups, or confidential operational files.

### [EduRAG — Intelligent Educational Knowledge Assistant](https://github.com/ranya20/ai-knowledge-manager)

Multimodal **Retrieval-Augmented Generation (RAG)** system designed to transform heterogeneous educational resources into an interactive knowledge base.

The system processes **PDF documents, scanned files, images, and web resources**, combining document extraction, OCR, preprocessing, embeddings, vector retrieval, and contextual LLM generation.

The pipeline integrates:

- multimodal document ingestion;
- OCR and document processing;
- web content extraction;
- semantic chunking and embeddings;
- **FAISS vector search**;
- contextual information retrieval;
- LLM-based answer generation.

The project focuses on building a structured knowledge pipeline capable of retrieving relevant information from different document formats and generating context-aware responses.
